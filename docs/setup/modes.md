# Сравнение ask и code

- `ask` прочитал `README.md`, `Makefile` и `docker-compose.yml`, предложил план раздела и команды проверки, но файлы не менял.
- `code` проверил те же источники и добавил в `README.md` раздел «Как проверить, что сервис жив»; отдельного разрешения не спрашивал, так как правка была прямо запрошена.
- Для разбора кода возьму `ask`: он не создаёт риск случайной правки. Когда изменение уже сформулировано, переключусь на `code`.

## ★ Основные агенты

- `code` — читать и менять файлы, запускать команды и проверки.
- `ask` — читать проект и объяснять, не изменяя файлы.
- `plan` — исследовать код и составлять план до реализации.
- `debug` — исследовать сбой, запускать диагностику и локализовать причину.
